-------De que va cada programa-------
BinarioInteractivo.java: Pide números enteros positivos y los convierte a binario,
te pregunta si quieres seguir convirtiendo más números o salir.
CabanaDelMisterio.java: Sistema de préstamos donde registras a un cliente y puedes calcular intereses (simple o compuesto),
comparar ambos o cambiar el monto, solo que tiene límite de operaciones y manejo de errores.
PiInteractivo.java: Calcula una aproximación del valor de pi  usando el método Monte Carlo que es
una simulación de lanzamiento de dardos a un círculo.
